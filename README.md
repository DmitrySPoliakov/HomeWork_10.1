# Виджет банковских операций

Проект предназначен для фильтрации и сортировки данных о банковских операциях клиента.

## Требования и зависимости

Для работы проекта необходим **Python 3.10+**. 
Все зависимости и инструменты для разработки (линтеры, тесты) указаны в файле `pyproject.toml` (или `requirements.txt`).

### Установка зависимостей

Если вы используете **Poetry**:
```bash
poetry install
```

Если вы используете **pip**:
```bash
pip install -r requirements.txt
```

## Настройка и проверка качества кода

В проекте настроены инструменты для контроля качества кода в соответствии со стандартом PEP 8: `flake8` и `mypy`. 
Конфигурация линтеров считывается автоматически из файлов настроек проекта.

Для запуска проверок выполните в терминале:
```bash
# Проверка стиля кода
flake8 src/

# Проверка статической типизации
mypy src/

# Запуск тестов
pytest
```

## Использование разработанных функций

Модуль `src.processing` содержит функции:
* `filter_by_state(data, state='EXECUTED')` — фильтрация по статусу операции.
* `sort_by_date(data, reverse=True)` — сортировка по дате.

### Пример работы

```python
from src.processing import filter_by_state, sort_by_date

data = [
    {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
    {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}
]

# Фильтрация по умолчанию ('EXECUTED')
print(filter_by_state(data))

# Сортировка по убыванию даты
print(sort_by_date(data))
```
